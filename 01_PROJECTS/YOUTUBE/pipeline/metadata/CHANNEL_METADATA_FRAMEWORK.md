# Quantrove Channel Metadata Framework

**Purpose**: Establish permanent channel-level metadata defaults, recurring brand vocabulary, and strategic positioning so YouTube's recommendation algorithm understands Quantrove's content identity consistently across all releases.  
**Version**: 1.0.0  
**Authority**: Standing Channel Architecture  

---

## 1. Channel Audience Positioning & Identity

| Dimension | Standard Specification |
|---|---|
| **Channel Name** | **Quantrove** |
| **Handle** | `@Quantrove` ([youtube.com/@Quantrove](https://youtube.com/@Quantrove)) |
| **Core Proposition** | Data-driven documentaries explaining the hidden mathematical, algorithmic, and financial systems shaping the world. |
| **Aesthetic Standard** | Institutional Data Intelligence (clean vector plots, photorealistic B-roll, high-contrast dark mode). |
| **Tone of Voice** | Calm, authoritative, analytical, investigative observer. Never hype, never speculative, never retail clickbait. |
| **Primary Target Audience** | Intellectually curious tech/finance professionals, engineers, quants, investors, students, and lifelong learners seeking first-principles explanations of complex modern systems. |

---

## 2. Channel-Level Default Description Keywords & Vocabulary

Every upload description and channel summary incorporates elements from this standardized lexicon to build high-relevance algorithmic associations in YouTube's semantic index:

### Core Identity Keywords
`data-driven documentaries`, `quantitative analysis`, `financial machine learning`, `market microstructure`, `how algorithms work`, `empirical data`, `institutional finance`, `algorithmic execution`, `first principles explained`

### Controlled Brand Lexicon (Approved Phrasing)
- **Approved**: *"Every episode is built from primary empirical data."*
- **Approved**: *"Uncovering the mechanics behind modern markets and artificial intelligence."*
- **Approved**: *"First-principles visual breakdowns using mathematical animations and historical records."*
- **Forbidden**: *"Secret hack"*, *"Get rich quick"*, *"Crazy prediction"*, *"Shocking truth"*, *"Insane money glitch"*.

---

## 3. Permanent Channel-Level Default Description Block

This block is mandatory on every long-form upload, appended below the episode-specific narrative text:

```text
Quantrove: data-driven documentaries on AI, markets, and the systems behind them. Every episode is built from primary data.

Channel: https://youtube.com/@Quantrove
Playlists: https://www.youtube.com/@Quantrove/playlists

Educational content only. Not financial, investment, or trading advice. Markets involve risk.
```

---

## 4. Tier 1 Core Channel Tags (Permanent Foundation)

These 5 tags form the anchor of every video upload, establishing cross-episode semantic clustering:

```text
Quantrove, quantitative finance, finance explained, financial markets, how markets work
```

*Character length*: 87 characters (including commas).

---

## 5. Architectural Principles

1. **Modular 3-Tier Assembly**: Metadata is never generated from scratch. It is assembled systematically:
   $$\text{Metadata} = \text{Tier 1: Core Channel} + \text{Tier 2: Pillar / Playlist} + \text{Tier 3: Episode Specific}$$
2. **Human Audience First**: Titles and descriptions are written for human curiosity and comprehension; algorithmic SEO follows structure rather than keyword stuffing.
3. **Zero Disconnect**: On-screen graphics, narration, title keywords, and description timestamps must share identical terminology.
