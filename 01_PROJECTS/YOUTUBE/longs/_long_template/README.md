# Episode Template

Copy this directory when scaffolding new video episodes.

Structure:
- `01_scripts/`: Narration and scene breakdown markdown
- `02_assets_code/`: Generation scripts and asset code
- `02_assets_code/renders/`: High-resolution rendered charts and animations
- `03_metadata/`: Titles, chapters, descriptions, and tags
- `voiceover/`: Voiceover MP3/WAV audio files
